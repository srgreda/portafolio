# Portafolio de proyectos web

La página principal (`index.html`) reúne cuatro proyectos estáticos. Cada proyecto está enlazado desde su carpeta, así que GitHub Pages puede servirlos desde el mismo repositorio.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub llamado `portafolio`. Para publicar con GitHub Pages en un plan gratuito, elige visibilidad **Public**.
2. Sube el contenido de esta carpeta al repositorio, incluyendo `index.html`, este `README.md` y las carpetas `listas de tarea antigravity` y `negocios de ropa`. No subas solo los archivos de la página principal: también hacen falta las carpetas de los proyectos.
3. En GitHub, abre el repositorio y ve a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama `main` y la carpeta `/(root)`, y pulsa **Save**.
6. Espera unos minutos. GitHub mostrará la dirección pública en esa misma sección; normalmente será `https://TU-USUARIO.github.io/portafolio/`.

La portada enlaza a los cuatro proyectos dentro del mismo repositorio. Al actualizar los archivos, vuelve a subirlos o sincroniza los cambios con GitHub; Pages publicará la nueva versión automáticamente.
